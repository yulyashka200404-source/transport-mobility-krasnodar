# Транспортная мобильность Краснодарского края — The Sims 4 Edition

Интерактивная аналитическая карта, визуализирующая транспортную мобильность населения Краснодарского края за 2025 год в стилистике интерфейса игры The Sims 4.

## 🚀 Запуск проекта

1. Убедитесь, что у вас установлен Python 3.x.
2. Откройте терминал в папке проекта `transport_mobility_krasnodar_2025`.
3. Запустите скрипт обработки данных:
   ```bash
   python build_map.py
